# **App Name**: Neon Notes

## Core Features:

- Password Protection: Require a single master password before accessing the notes page.
- Note Creation: Create new notes with a title, auto-generated date, and text content.
- Note Viewing/Editing: View and edit existing notes.
- Note Deletion: Delete unwanted notes.
- Note Search: Filter notes by title and content using a search bar.
- Copy to Clipboard: Provide a button to quickly copy note content to the clipboard.
- Relative Time Display: Display the time of the notes using relative time format such as “2 days ago”.

## Style Guidelines:

- Primary color: Electric blue (#7DF9FF) for a techy and vibrant feel.
- Background color: Dark gray (#222222) to enhance the neon effect.
- Accent color: Purple (#A78BFA) for interactive elements.
- Font: 'Orbitron', a sans-serif font, to convey a futuristic aesthetic. Note: currently only Google Fonts are supported.
- Notes displayed as cards in a responsive grid layout.
- Glowing neon borders and hover effects for the note cards using smooth CSS animations.
- Glitch effect error message when the wrong password is provided.
